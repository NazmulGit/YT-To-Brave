Welcome — one-time setup

To open YouTube links in Brave, you need to install the tiny native host helper.

  1. Open the native-host folder inside this extension
  2. Double-click install.bat (or install-auto.bat / install-manual.bat)
  3. Reload the extension at chrome://extensions
